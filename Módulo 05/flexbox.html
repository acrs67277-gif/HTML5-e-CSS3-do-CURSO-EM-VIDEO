CSS Flexible Box Module Level 1

O CSS Flexible Box Module Level 1 (mais conhecido como Flexbox) é um modelo de layout da W3C projetado para proporcionar uma maneira mais eficiente de organizar, alinhar e distribuir espaços entre itens em um contêiner, mesmo quando o tamanho deles é desconhecido ou dinâmico.
Antes do Flexbox, os desenvolvedores dependiam de truques com float, display: inline-block ou tabelas, o que tornava tarefas simples (como centralizar um elemento verticalmente) complexas e frustrantes.

Principais Conceitos e Funcionamento

O Flexbox funciona com base na ideia de um Contêiner Flexível (display:fleou display: inline-flex) que controla o comportamento dos seus Itens Flexíveisdiretos. layout opera ao longo de dois eixos principais:

Eixo Principal (Main Axis): É a direção principal na qual os itensãodispostos (linha por padrão, horizontal da esquerda para a direita). Pode ser alteradocoa propriedade flex-direction.

Eixo Cruzado (Cross Axis): É o eixo perpendicular ao Eixo Principal(verticapor padrão, de cima para baixo).

Vantagens e Recursos Principais

  1. Alinhamento Direcionável: É extremamente simples alinhar itens no centronaspontas ou distribuídos uniformemente usando propriedades como justify-content ecode>align-items.
  2. Responsividade Natural: Os itens podem crescer (flex-grow) oudiminui(flex-shrink) automaticamente para preencher o espaçodisponível ou evitatransbordamento na tela.
  3. Ordem Flexível: A propriedade order permite alterar a ordem visual doselementos nnavegador sem precisar modificar a estrutura do código HTML.
  4. Quebra de Linha (Wrap): Com flex-wrap: wrap, os itens podem quebrar para alinhseguinte de forma organizada quando o espaço do contêiner acabar.

Exemplo Prático de Código

                    
                        .container {
                            display: flex;
                            justify-content: space-between; /* Distribui o espaço horizontalmente */
                            align-items: center;            /* Centraliza verticalmente */
                        }

Nota: Para layouts bidimensionais complexos (linhas e colunas simultâneas), opadrão moderno recomendado em conjunto com o Flexbox é o CSS Grid Layout.

CSS Grid Layout Module Level 1/2

O CSS Grid Layout Module é o sistema de layout mais poderoso disponível no CSS moderno.Diferentedo Flexbox — que lida primariamente com uma dimensão por vez (linha ou coluna) —, oGrid foi criadopara trabalhar em duas dimensões simultaneamente: linhas e colunas (eixos X eY).

Com ele, vocêconsegue desenhar a estrutura inteira de uma página web (como cabeçalho, menulateral, área deconteúdo principal e rodapé) como se estivesse montando um tabuleiro ou umaplanilha.

Diferença entre o Level 1 e o Level 2

W3c
  • Level 1 (Nível 1):Introduziu o sistema completo de grades bidimensionais na Web. Permite definir linhas e colunas, posicionar itens com precisão cirúrgica usando números de linhas ou nomes, criar espaços automáticos (gap) e usar unidades flexíveis inovadoras, como a unidade fr (fração de espaço).
  • Level 2 (Nível 2): Trouxe uma adição muito aguardada e poderosa chamada Subgrid.
    • O problema antes do Nível 2: Se você criava uma grade principal e colocava um card dentro dela, os elementos internos daquele card não conseguiam se alinhar perfeitamente com as linhas da grade principal.
    • A solução com o Subgrid: Permite que um elemento filho que já faz parte de uma grade também se torne uma grade, herdando e alinhando suas próprias linhas ou colunas diretamente com o layout do elemento pai.

Principais Vantagens do CSS Grid

  • Controle Bidimensional: Gerencia linhas e colunas ao mesmo tempo, ideal para estruturas de páginas complexas e dashboards.
  • Unidade Fracional (fr): Facilita a distribuição proporcional do espaço disponível (ex: grid-template-columns: 1fr 2fr 1fr).
  • Áreas Nomeadas (grid-template-areas): Permite "desenhar" o layout visualmente no código usando apelidos para as seções, tornando a manutenção extremamente simples.
  • Menos Código: Elimina a necessidade de cálculos matemáticos complexos de margens e larguras percentuais ou o uso de hacks antigos.

Exemplo Prático de Código

            
                .pagina-dashboard {
                    display: grid;
                    /* Define 3 colunas e 2 linhas */
                    grid-template-columns: 250px 1fr 1fr;
                    grid-template-rows: 80px 1fr;
                    grid-template-areas: 
                        "sidebar header header"
                        "sidebar conteudo conteudo";
                    height: 100vh;
                    gap: 1rem;
                }

                    .sidebar { grid-area: sidebar; }
                    .header { grid-area: header; }
                    .conteudo { grid-area: conteudo; }

Resumo prático: Use Flexbox quando precisar alinhar itens em uma única direção (uma linha de botões, um menu de navegação). Use Grid quando precisar estruturar o layout macro de uma página ou organizar elementos em uma grade completa de linhas e colunas.

Flexbox CSS2.1

O CSS 2.1 é uma recomendação antiga da W3C (concluída na década de 2000) focada em conceitos tradicionais de layout, como o fluxo de texto normal, posicionamento (position: relative/absolute), flutuações (float) e tabelas. O Flexbox foi um conceito criado anos depois para resolver as limitações do CSS 2.1.

  1. Aqui está o que aconteceu na história das especificações:

  • A Tentativa Antiga (Início dos Anos 2000): Antes do Flexbox moderno, a W3C tentou criar especificações primitivas para caixas flexíveis (houve rascunhos chamados de CSS Flexible Box Layout Model por volta de 2007–2009 inspirados em ideias antigas de XUL da Mozilla), mas elas nunca chegaram a ser padronizadas no CSS 2.1 e foram descartadas por terem suporte inconsistente e problemas de design.

  • O Flexbox Moderno (Level 1): O Flexbox que usamos hoje foi totalmente reescrito e padronizado pelo W3C Candidate Recommendation para o CSS3 (conhecido oficialmente como CSS Flexible Box Layout Module Level 1), lançado de forma estável pelos navegadores a partir de 2012/2013.

Portanto, se você ouvir falar de Flexbox associado a versões antigas do CSS, trata-se de rascunhos antigos e obsoletos que foram substituídos pelo padrão moderno que conhecemos hoje.

Block Layout

O Block Layout (ou Layout em Bloco) é o modelo de posicionamento padrão do CSS para elementos de nível de bloco, como 
div, p, section, h1 e ul
. Ele faz parte do fluxo normal (normal flow) da página e determina como os navegadores organizam esses elementos na tela antes de qualquer estilização avançada como Flexbox ou Grid.

Principais Características do Block Layout

Empilhamento Vertical: Os elementos de bloco são empilhados uns sobre os outros, do topo para a base da página. Cada elemento novo começa obrigatoriamente em uma nova linha abaixo do anterior. Largura Total por Padrão: Por padrão, um elemento em bloco ocupa 100% da largura disponível do seu contêiner pai, esticando-se horizontalmente (a menos que uma largura específica seja definida). Controle de Altura e Espaçamento: É possível definir propriedades de largura (width), altura (height), margens (margin) e preenchimento (padding) livremente. Margens Verticais (Margin Collapse): Um comportamento clássico do Block Layout é que as margens verticais superiores e inferiores de elementos adjacentes podem se fundir (colidir) em uma única margem, em vez de somarem seus valores.
